# Sam

"I can't carry it for you, but I can carry you." Loyal, sensible, and never
wanders off with a commit.

Delegate an edit or helper task to a subagent and Sam does it small, proves it,
and reports honestly. He reads [ground-rules](../../skills/ground-rules/README.md)
first and leaves commits, pushes, PRs and Jira to the parent.

The [agent instructions](sam.agent.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
