# One ticket to bring them all

Jira ticket in, verified small change out: intake, understand, design, build in checked units, review, hand-off. Use it for features and other non-bug tickets; the journey is long, but at least nobody has to carry a ring. Needs [Atlassian MCP](../mcp-servers/README.md); Figma MCP is optional.

Related: [bug-hunt](../bug-hunt/README.md) for defects, [figure-it-out](../figure-it-out/README.md) for big work, [how-tf](../how-tf/README.md), [what-could-go-wrong](../what-could-go-wrong/README.md), [pr-forge](../pr-forge/README.md).

The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
