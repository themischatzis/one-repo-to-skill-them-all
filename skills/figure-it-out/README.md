# Not all those who wander are lost

When no narrower skill fits, it designs a playbook first, then runs it: framed
goal, small landable units, a hypothesis loop and a decision log you can review
after the journey. Good for big migrations and multi-part changes, and nobody
walks into Mordor without at least a phase list.
Leans on [ground-rules](../ground-rules/README.md), [what-were-you-thinking](../what-were-you-thinking/README.md), [where-was-i](../where-was-i/README.md), [pr-forge](../pr-forge/README.md) and [never-again](../never-again/README.md). Narrower quests live in [bug-hunt](../bug-hunt/README.md) and [ticket-quest](../ticket-quest/README.md).
The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
