# Riddles in the dark

Independent subagents try to break your change or design, and only findings
proven by a run survive. It reports and never fixes. Use it before shipping
something contested; Gollum asks nasty questions too, but at least these
come with repro commands.
Pairs with [what-could-go-wrong](../what-could-go-wrong/README.md) and [review-change](../review-change/README.md).
The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
