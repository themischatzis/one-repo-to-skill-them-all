# You shall not repeat that mistake

When the same mistake happens twice, stop nagging and change the repo so it
can't. It prefers architecture, then types, then lints, then tests, and docs
last, and it asks before landing anything. Think Gandalf on the bridge, but
with a CI check instead of a staff.
Pairs with [skill-retro](../skill-retro/README.md) and [ground-rules](../ground-rules/README.md).
The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
