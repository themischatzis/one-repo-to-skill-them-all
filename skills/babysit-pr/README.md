# Light the beacons, the PR calls for aid

Watches an open PR through conflicts, review threads and CI until it is merge-ready, then stops, because merging is your call, not Gondor's. Reach for it when a PR is open and you would rather not stare at it. Conflicts go to [untangle-this](../untangle-this/README.md), and the PR itself comes from [pr-forge](../pr-forge/README.md).

The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
