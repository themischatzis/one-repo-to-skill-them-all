# What did we just wake up in the deep?

Hunts for breakage beyond the diff, then proves the one fact the change is safe
because of by running code, not by writing a persuasive essay. Read-only: it
reports, it doesn't fix. Reach for it on any small diff that looks too innocent,
because the Balrog also looked like a minor change to the mine.
Pairs with [tear-it-apart](../tear-it-apart/README.md) and [review-change](../review-change/README.md).
The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
