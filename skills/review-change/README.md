# The second pair of eyes

Reviews a PR, branch or diff against its intent, with evidence for each finding. Reports, never posts. Use it before merging; like Gandalf at the Bridge, it says "you shall not pass" only when it can prove why.

Related: [what-could-go-wrong](../what-could-go-wrong/README.md), [tear-it-apart](../tear-it-apart/README.md), [babysit-pr](../babysit-pr/README.md).

The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
