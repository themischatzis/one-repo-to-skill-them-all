# Reading the old scrolls

Recover why code looks the way it does from git, PRs and Jira, and whether the reason still holds. Read-only. Use it before deleting something that looks pointless; even the smallest line may have been written by someone with a very good reason, or a very bad Tuesday. Reads tickets through [Atlassian MCP](../mcp-servers/README.md) when a Jira key turns up.

Related: [how-tf](../how-tf/README.md), [what-could-go-wrong](../what-could-go-wrong/README.md), [bug-hunt](../bug-hunt/README.md).

The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
