# Untangling the branches

Rebases a branch and resolves conflicts by intent, with a rollback point and verification. Reach for it when a PR has conflicts; two branches may not be one, but they can be reconciled without a Council of Elrond.

Related: [pr-forge](../pr-forge/README.md), [babysit-pr](../babysit-pr/README.md), [ground-rules](../ground-rules/README.md).

The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
