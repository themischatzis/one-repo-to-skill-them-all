# Nobody expects the decision log

A one-row-per-decision TSV log so unattended or multi-phase runs can be reviewed
after the fact, with no need to ask "what were you thinking?" at 2 a.m. Reach for
it on long, autopilot or multi-phase runs; `scripts/log.sh` appends a row. Pairs
with [figure-it-out](../figure-it-out/README.md) and [where-was-i](../where-was-i/README.md).
The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
