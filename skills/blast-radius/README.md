# What does this change wake up?

Review a change for breakage beyond the diff, and prove the one fact it is safe
because of by running code instead of writing a persuasive essay. Read-only.
The [skill instructions](SKILL.md) rank evidence from "someone said so" to
"reproduced in the app".

Adapted from the `blast-radius` skill in [Cursor's pstack](https://github.com/cursor/plugins/tree/main/pstack/skills/blast-radius).
Install it with the [repository setup guide](../../README.md#equip-your-skills).
