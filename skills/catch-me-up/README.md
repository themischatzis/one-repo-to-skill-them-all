# Catch me up (gaze into the palantir, briefly)

A plain-words catch-up after long or parallel work: what changed, and every call that waits on you. Read-only, and unlike Pippin, it touches nothing. Reach for it after an autopilot or subagent-heavy run, or when you need something explained simply. For resuming across sessions, see [where-was-i](../where-was-i/README.md).

The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
