# Hunt the bug to its lair

Jira bug in, reproduced and root-caused fix out: reproduce, eliminate hypotheses, test first, verify, review. Reach for it when something is broken, because one does not simply patch into Mordor without knowing where the bug lives. Needs [Atlassian MCP](../mcp-servers/README.md) to read tickets.

Related: [create-jira-bug](../create-jira-bug/README.md), [tdd-bug-fix](../tdd-bug-fix/README.md), [what-could-go-wrong](../what-could-go-wrong/README.md), [tear-it-apart](../tear-it-apart/README.md).

The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
