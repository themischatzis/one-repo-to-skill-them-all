# Hunt the bug to its lair

Jira bug in, reproduced and root-caused fix out: reproduce, eliminate hypotheses, test first, verify, review. Works with [create-jira-bug](../create-jira-bug/README.md) and needs [Atlassian MCP](../mcp-servers/README.md) to read tickets.
The [skill instructions](SKILL.md) have the detail.

Adapted from Cursor's [pstack](https://github.com/cursor/plugins/tree/main/pstack/skills) (Bug fix playbook) and tuned for Copilot CLI subagents. Install with the [repository setup guide](../../README.md#equip-your-skills).
