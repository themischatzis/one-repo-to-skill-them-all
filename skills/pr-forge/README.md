# Forge the pull request in the fires of Mount Doom

One does not simply walk into review with a 40-file diff. This skill turns finished work into small ordered commits, a conventions-checked branch and title, and a PR body a reviewer can absorb in a minute. Reach for it when the work is done and it is time to open the PR.

Afterwards, hand the PR to [babysit-pr](../babysit-pr/README.md) and make the title and body less robotic with [unslop](../unslop/README.md). The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
