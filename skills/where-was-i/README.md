# Where was I? There and back again

Pause work safely, pick up a previous session, or recall where you left off, so a journey of unexpected length does not start from the Shire every time. Reach for it when logging off, resuming a branch, or asking what you were doing last Tuesday. Pairs with [what-were-you-thinking](../what-were-you-thinking/README.md) and [who-did-this](../who-did-this/README.md).

The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
