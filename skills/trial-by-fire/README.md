# Walking through the fire

Blind test of a skill change: did it actually change behaviour, or did it just
look wise in a cloak? Runs each variant at least twice with
[divide-and-conquer](../divide-and-conquer/README.md), then judges blind. Pair it with the weekly
[skill-retro](../skill-retro/README.md). Opt-in and costly, since it runs several agents.
The [skill instructions](SKILL.md) have the detail.

Install with the [repository setup guide](../../README.md#equip-your-skills).
