# The Council of Designs

Competing attempts at one task, judged blind against a rubric, then merged into
the best base. Opt-in and costly, as every council is: many voices, one decision,
and nobody gets the ring. Built on [divide-and-conquer](../divide-and-conquer/README.md).
The [skill instructions](SKILL.md) have the detail.
