# Backend

The dwarves of the codebase: they dig deep and mind the foundations.

Server-side work in WordPress/PHP (anything named `wp*`), Node or Java. Edits
and runs tests inside its brief, and leaves commits to the parent. Its
[guard](../../guard/README.md) hook blocks git changes, deploys, downloads,
secrets and writes outside the working directory.

The [agent instructions](backend.agent.md) have the detail. Usually started by
[gandalf](../../agents/gandalf/README.md).

Install with the [repository setup guide](../../README.md#equip-your-skills).
