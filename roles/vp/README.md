# VP

Denethor, but sensible. Coordinates several pieces of work, checks they fit
together, and recommends approve, reject or escalate with reasons. The decision
stays yours. Read-only.

The [agent instructions](vp.agent.md) have the detail. Enforced by the
[guard](../../guard/README.md) as a read-only role.

Install with the [repository setup guide](../../README.md#equip-your-skills).
