# Manager

Aragorn at the war council. Breaks a goal into small ordered tasks with a role,
paths and a check for each. Read-only; it reports the list and Gandalf runs it.

The [agent instructions](manager.agent.md) have the detail. Enforced by the
[guard](../../guard/README.md) as a read-only role.

Install with the [repository setup guide](../../README.md#equip-your-skills).
